# 记忆星图 · Memory Star Map

一个运行在 **DeepSeek Harness** Web 界面里的记忆星图插件。把值得记住的事变成星图上的星星：按遗忘曲线慢慢暗下去，被回忆时重新点亮，并且每次回忆都会让它的「突触」更牢固一点。

## 功能

- **星图**：3D 投影的星群、星云、粒子环绕、发光纤维、悬停卡片、缓慢自转
- **遗忘**：每段记忆有稳定性 `S`，清晰度 `R = e^(-距上次回忆的天数 / S)`；越久越暗，低于阈值进入「沉眠」
- **强化**：手动回忆、Agent 检索、对话中自动召回，都会让 `S` 增长并把清晰度拉回 100%（间隔重复 / 突触强化）
- **自动记忆**：对话里像「个人信息 / 偏好 / 重要经历 / 承诺」的内容自动入库；也可以由 Agent 通过 `memory_starmap` 工具主动保存
- **自动回忆**：你每发一条消息，系统检索最相关的 3 段记忆注入上下文，并自动强化它们
- **其他**：时间推演（+7/+30/+90/+365 天）、睡眠整理、导入导出、星团聚焦、时间轴清晰度曲线

## 安装

需要已安装 DeepSeek Harness 桌面版。

1. 把整个 `memory-starmap` 目录放到本机。
2. 在 Harness 的插件管理里安装这个本地 bundle（包名 `@local/memory-starmap`），或在会话里用 `plugin_manager` 的 `install_bundle` 指向该目录。
3. 安装后刷新页面，左侧栏会出现一个星座图标。

## 使用

- 点左侧栏的星座图标打开星图。
- 拖动旋转、滚轮缩放、双击复位；点星星看详情。
- 顶部「自动记忆」开关控制对话自动抓取与自动召回。
- 新增记忆时，第一个标签决定它落在哪个星团。

## 数据

记忆保存在 Host 进程的用户目录：

```
~/.dsh/memory-starmap/memories.json
```

界面每 4 秒与这份共享存储同步一次；浏览器 `localStorage` 只作为降级备份。

## 目录结构

| 文件 | 作用 |
| --- | --- |
| `index.js` | Host 半：记忆存储、`memory_starmap` 工具、自动抓取/召回、HTTP 桥 |
| `client.js` | Client 半：星图渲染、交互、详情面板、同步 |
| `cordis.patch.yml` | 插件装配补丁 |
| `locale/*.json` | 插件标题与描述 |
| `icon.svg` | 插件图标 |
